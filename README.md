# CrispScale

CrispScale — это форк Mod-а [Advanced UI Scaling](https://github.com/Qendolin/BetterUIScale), предназначенный для **Minecraft 26.2 (Fabric)**.

Он улучшает реализацию масштабирования GUI в Minecraft, добавляя более чем в 10 раз больше вариантов масштабирования интерфейса, а также плавный рендеринг шрифтов.

Расширенное масштабирование GUI с плавным рендерингом шрифтов!

## Требования

- Minecraft **26.2**
- [Fabric Loader](https://fabricmc.net/) >= 0.19.0
- [Fabric API](https://modrinth.com/mod/fabric-api)
- Java **25**
- (Рекомендуется) [Mod Menu](https://modrinth.com/mod/modmenu)

## Установка

1. Установи [Fabric Loader](https://fabricmc.net/use/installer/) для Minecraft 26.2.
2. Скачай [Fabric API](https://modrinth.com/mod/fabric-api) и [CrispScale]([RELEASE_URL]).
3. Положи оба файла в папку `mods` в игровом каталоге.
4. Запусти игру.

## Сборка из исходников

```
./gradlew build
```

Готовый jar появится в папке `build/libs/`.
